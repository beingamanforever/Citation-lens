Shared evaluation method

  • {{TOTAL_TASKS}} tasks and {{TOTAL_ANCHORS}} must-find anchors, including {{RECENT_ANCHORS}} recent anchors. {{DEVELOPMENT_TASKS}} tasks were used for development and {{HELDOUT_TASKS}} were held out.
  • Matched within each host. Web and Lens arms use the same agent model, effort, prompt, schema, call budget and deadline. Results compare arms within Codex or within Claude, not the hosts against each other.
  • Relevance was labeled once per paper per task. The pairwise comparison was run twice with answer order swapped; the final label reconciles those two votes.
  • Quote matching preserves scientific notation. The checker collapses whitespace only, so operators, signs and punctuation remain part of the match. It checks abstracts first and arXiv full text when available.
  • Citation proof keeps sources distinct. Primary-reference identifier and complete title-author-year matches are reported separately from index reference IDs. Unverified URLs remain visible.
  • Pairwise masking has limits. Each completed host panel reports the export's masking metadata. Removing explicit identifiers does not remove workflow or writing-style cues.
