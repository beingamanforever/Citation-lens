What the measured package did

Search wide

Query Semantic Scholar, OpenAlex and arXiv together and fuse the results.

Expand the graph

Follow references and citing papers from selected seeds, preserving partial provider results and gaps.

Balance the list

Interleave foundational work, follow-ups and recent papers rather than returning one ranking.

Preview, then read

Return compact cards first and fetch abstracts, text or figures on demand.

The measured package was {{PACKAGE}}. Its saved Lens tool-result payload averaged {{LENS_BYTES_KB}} per attempt.

How it was measured

  • {{TOTAL_TASKS}} tasks and {{TOTAL_ANCHORS}} must-find anchors, including {{RECENT_ANCHORS}} recent anchors. {{DEVELOPMENT_TASKS}} tasks were used for development; {{HELDOUT_TASKS}} were held out and each ran {{REPETITIONS}} times per arm.
  • Same conditions except the research tools. Both arms used {{MODEL}} at {{EFFORT}} effort, the same prompt and schema, a {{TOOL_BUDGET}}-call budget and a {{DEADLINE}} s deadline.
  • Quote matching preserves scientific notation. The current revision-2 checker collapses whitespace only, so operators, signs and punctuation remain part of the match. It checks abstracts first and arXiv full text when available.
  • Citation proof keeps sources distinct. Of {{VERIFIED_PROOF}} verified links, {{PRIMARY_PROOF}} used the citing paper's own reference metadata: {{PRIMARY_IDENTIFIER_PROOF}} matched cited-paper identifiers and {{PRIMARY_TITLE_PROOF}} matched complete title-author-year evidence. Another {{INDEX_PROOF}} used separately labelled index reference IDs.
  • Judgment was blinded and order-swapped. The judge was {{JUDGE_MODEL}} at {{JUDGE_EFFORT}} effort. Pooled relevance labels and pairwise comparison ran twice with the answer order swapped.

Read before relying on this

  • This is an earlier package measurement. Results apply to package {{PACKAGE}}. Production repairs made after that snapshot need a new evaluation.
  • The Claude comparison is still running. Claude login and a real request now work; no Claude result is included here until the paired run finishes.
  • The judge uses the same model family as the agents. Both arms are equally exposed, but the labels are not human-calibrated.
  • Lens was slower and completed one fewer attempt. Its quality gains on this benchmark came with about {{TIME_CHANGE}} mean elapsed time and incomplete token reporting.
